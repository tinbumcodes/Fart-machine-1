ERASER ORACLE - Android install package
=======================================
1) Upload every file in this folder (keep the icons folder) to any HTTPS static host:
   GitHub Pages, Netlify Drop, Cloudflare Pages, etc.
2) On the phone, open that address in Chrome, tap the menu (three dots),
   then "Install app" or "Add to Home screen". It opens full screen like an app and works offline.

To make a real .apk for sharing or the Play Store: paste your hosted address into pwabuilder.com
and choose Android. Or ask Claude Code to wrap this folder with Bubblewrap or Capacitor.
